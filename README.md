## 📌 About the Project

**MedReminder** is a smart medication reminder web application designed to help patients manage their treatments easily and safely.  

The system allows users to schedule their medications and receive **automatic reminders at the right time**, reducing the risk of missed doses and improving treatment adherence.

This project can also help caregivers or family members monitor patients’ medication intake.

---

## 🎯 Objectives

- Help patients take their medication on time ⏰  
- Reduce human forgetfulness 💊  
- Improve healthcare follow-up 👨‍⚕️  
- Provide a simple and accessible interface 📱  

---

## ✨ Features

### 👤 User Features
- User registration and login system  
- Add medication (name, dose, frequency, time)  
- Edit or delete medication schedules  
- View full medication list  

### 🔔 Reminder System
- Automatic notifications at scheduled time  
- Alerts for missed doses  
- Repeated reminders until confirmed  

### 👨‍👩‍👧 Caregiver Mode (Optional)
- Allow family members or doctors to monitor patient adherence  
- View medication history  

### 📊 Tracking
- History of taken / missed doses  
- Progress tracking dashboard
